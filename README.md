# Meu Portfólio - Site Pessoal

Um site de portfólio responsivo e moderno desenvolvido com HTML, CSS e JavaScript.

## 📁 Estrutura dos Arquivos

```
meu-portfolio/
├── index.html      # Arquivo principal HTML
├── style.css       # Estilos CSS
├── script.js       # Funcionalidades JavaScript
└── perfil.jpg      # Foto de perfil (você precisa adicionar)
```

## 🚀 Como Usar

1. **Abra o arquivo `index.html`** no seu navegador
   - Clique duas vezes em `index.html` ou
   - Clique com botão direito > Abrir com > Navegador

2. **Adicione sua foto de perfil**
   - Coloque uma imagem chamada `perfil.jpg` na mesma pasta
   - Ou edite a linha do `<img>` no HTML para o nome correto da sua foto

3. **Personalize o conteúdo**
   - Edite o arquivo `index.html` para adicionar seu conteúdo pessoal
   - Modifique cores e estilos no arquivo `style.css`

## 📋 Seções do Site

### 1. **Cabeçalho (Header)**
- Título do portfólio
- Menu de navegação com links para: Sobre, Projetos e Contato

### 2. **Seção Sobre Mim**
- Foto de perfil circular
- Descrição profissional
- Destaca sua formação em Tecnólogo para Sistema de Internet

### 3. **Galeria de Projetos**
- Exibe seus projetos principais
- Links diretos para o GitHub
- Cards com efeito hover

### 4. **Formulário de Contato**
- Campos: Nome, E-mail, Telefone e Mensagem
- Validação básica de campos obrigatórios
- Feedback ao enviar

### 5. **Rodapé (Footer)**
- Informações de copyright
- Ano atual
